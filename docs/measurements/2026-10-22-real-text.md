# Real-text measurement: precision, spans, recall, clean-prose false positives

Date: 2026-10-22. Bead: lcr-uce (parent dotfiles dot-1ij4xz.6). Tool: `cite-detect` 0.1.0
built from this tree (`cargo build --release -p cite-detect`), run as
`cite-detect --format jsonl --input text --fail-on never FILE`.
Machine-readable results, including every hand label: [`2026-10-22-real-text.json`](2026-10-22-real-text.json).
Corpus manifest (URLs, sha256, word counts): [`corpus/manifest.json`](../../corpus/manifest.json).
Scripts: the one-off Python helpers used for this run are not committed, because the repo gate allows no new Python. They were kept as run artifacts. The Reproduce section below describes each step so it can be redone; porting the helpers to a Rust `measure` tool is a follow-up.

> **Who labeled this.** Every label, span judgment and missed-citation count in this report was
> made by an AI agent (Claude), not a lawyer. There was one labeler and no second rater, so
> inter-rater agreement was not measured. The agent knows Bluebook and state citation forms well,
> but it can be wrong on edge cases (record cites, internal cross-references, page furniture).
> Treat the numbers as a careful first pass, not ground truth.

> **Rule provenance.** All 108 rules in the registry say `"measured": {"precision": "unmeasured"}`
> and `"opened": false`. This report does **not** change them. It is a manual evaluation, not an
> eval run, so no rule's `measured` block was written.

## Method

### A. Corpus

42 public opinions and decisions, fetched 2026-10-22. Each has its URL, court, date, the sha256
of the extracted text and a word count in `corpus/manifest.json`. The texts are in
`corpus/cache/` (gitignored, not committed).

- **CourtListener API v4 search**, anonymous (no key): for each court, the newest results in a
  date window that have a stored PDF (`local_path`). PDFs come from `storage.courtlistener.com`.
  Opinions shorter than 1,500 words were skipped, because those are orders or one-page dispositions.
  U.S. Supreme Court: the June 27, 2025 merits opinions. The N.Y. Court of Appeals had only HTML,
  so tags were stripped.
- **govinfo USCOURTS** (the `published` and `granules` listing API with the public `DEMO_KEY`, which
  is not stored anywhere; PDFs from `www.govinfo.gov/content`): four district-court opinions
  (E.D. Tex., D.N.M., D. Mass., N.D. Ohio). Four more were under 1,500 words and dropped.
- **uspto.gov PTAB precedential/informative page**: five PTAB decisions (Appeals Review Panel,
  Director Review, IPR, ex parte appeal). These were taken regardless of length; one is 942 words.
- **Not reached:** TTAB. The uspto.gov TTAB precedent URLs I tried returned 404, and TTABVUE and the
  reading room are JavaScript apps, so there are 0 TTAB decisions. S.D.N.Y. has no opinions after
  2019 on CourtListener, and the anonymous 50/hour limit cut off further district-court searches.
- Text extraction: `pdftotext` (poppler) default mode, UTF-8. PDF artifacts were left in on purpose
  (running heads, footnote numbers inline, split words), because that is what real input looks like.

### B. Precision and span labeling

The run produced 4,272 citation records across 65 rules. That is more than 600, so I labeled a
**stratified sample**. For every rule with 10 or fewer detections, every detection was labeled.
For larger rules, max(10, ceil(8%)) detections were drawn uniformly at random with
`random.Random(20261022)` (the sampling helper). The sample has 526 detections.

Each one was labeled from about 110 characters of context before and 70 after (and more where
needed) as:

- **true**: a real citation of the claimed kind;
- **wrong kind**: a real citation, but of a different kind;
- **not a citation**.

Running heads like `Cite as: 606 U. S. 656 (2025)` and repeated PTAB captions are labeled *true*,
because they are well-formed citations. They are tagged `header` in the notes and counted
separately, because a linter would flag them as noise.

**Span convention.** A span is *exact* when it runs from the first character of the citation to
its last element.

- The first character is the case name if there is one; the signal ("See") is excluded.
- The last element is the pincite, subsection, or court/date parenthetical. Explanatory
  parentheticals are excluded.
- For statutes and regulations, the span must cover the code name, the full section, its
  subsections, and every listed section. A trailing `(West 2024)` or year is not required.

Otherwise the span is *truncated*, *overextended*, or both.

This convention is stricter than the tool's own design for short forms and law reviews (it
expects the short case name `Bruen,` to be in the span). Those categories are broken out below,
so a reader with a looser convention can recount.

Overall precision is reported two ways: the raw sample proportion, and a population-weighted
(stratified) estimate in which each rule is weighted by its share of the 4,272 detections. The
sampling standard error is about 0. Every stratum was either all true or fully enumerated, so the
SE carries no information about labeler error. The conservative figure weights each rule's Wilson
95% lower bound instead.

### C. Recall

Nine opinions were chosen for court variety and manageable length: the Ohio, Illinois, Delaware and
Texas supreme courts, D.D.C., D. Mass., the 5th and Federal Circuits, and a PTAB Director Review
order. Together they have 524 citations.

Each opinion was rendered with every detected span marked inline (a rendering helper) and
**read in full**. Every citation outside a detected span was counted as a miss.
A broad-regex helper (patterns for reporters, `§`, `R.C.`, `ILCS`, `IL`,
`WL`, record forms, `Paper N` and so on) was used as a cross-check, and every candidate it listed
was confirmed by reading.

Rules for counting:

- Page furniture (running heads, repeated captions, `Case: … Page: …` headers) is excluded from
  both the detected and the missed counts.
- A citation whose span is merely truncated counts as detected.
- Borderline references are listed in the JSON but not counted. These include bare "Rule 8" or
  "section 13-116" in running prose, statutes named without a cite, dictionaries, patents by number,
  and URLs.

## Top failure modes, with examples

1. **`us.ak.statute.code` fires on `AS` + any word.** 7/7 opinion detections and 3/3 prose detections
   are false: `DENIED AS MOOT`, `THOMAS M. COOLEY` (`AS M`), `THIS OPINION WAS FILED`, `NICOLAS BAURIN`,
   `TEXAS⏎certiorari`. The pattern `AS\s+§?\s*(?P<section>[0-9\w\-]+…)` has no leading `\b`, and
   its section may start with a letter. This rule accounts for every false positive measured.
2. **En dashes in section numbers truncate spans.** The SCOTUS and state-survey style
   `Ala. Code § 8–19G–3(a)` comes out as `Ala. Code § 8`. Fifteen state code rules plus `usc`,
   `federal_register`, `statutes_at_large`, `case_at` and `supra` are affected. The truncated span
   also yields a wrong `authority` key (section `8`).
3. **State-specific forms are not covered.** Ohio `R.C.` and `YYYY-Ohio-NNNN`, Illinois `YYYY IL NNNNNN`,
   `ILCS` and `Ill. 2d`, Delaware `8 Del. C. § 168`, small-caps `TEX. … CODE` and `TEX. R. APP. P.`
   This drives recall to 7% (Ohio) and 38% (Illinois).
4. **Page furniture is reported as citations.** 184 SCOTUS `Cite as:` running heads, 101 PTAB
   `IPR… (Patent …)` caption lines (mostly repeated on every page; a few are first-page captions) and
   33 circuit `Case: … Page:` header dockets: up to 318 detections (7.4% of all detections) that a
   linter would flag as unlinked. Counted with a heuristic, not hand-labeled.
5. **Case-name lookback fails inside parentheticals.** `(quoting Monell v. Dep't of Soc. Servs., 436 U.S. 658, 690 (1978))`
   yields `436 U.S. 658, 690 (1978)`. It also fails across PDF-split words (`AI Visualize, Inc. v. Nuance Commc 'ns, Inc.`).
6. **Short forms omit the short name.** `Bruen, 597 U.S. at 17` is spanned as `597 U.S. at 17`. A link on
   `Bruen` would then not overlap the citation core, so linking behaviour on real briefs depends on this.
7. **Westlaw and record pins are dropped.** `2002 WL 31040170, at *3 (E.D. La. Sept. 10, 2002)` ends at
   `31040170`. `Ex. 2106, 12:2–9` ends at `Ex. 2106`.
8. **Wrong authority, right kind (2 sampled).** `Ill. S. Ct. R. 315(a)` is read as the federal
   `us.fed.rules.supreme_court` (`S. Ct. R. 315(a)`, with `Ill.` dropped). `1838 Terr. of Wis. Stat. § 10, p. 366`
   is read as modern `Wis. Stat. § 10`. `Ohio Rev. Code Ann. §§ 2907.31(A)(1)` yields section `Ann`: the pattern allows only a single `§`, so the optional `Ann.` group backtracks and `Ann` becomes the section.

## Recommendations (one line each; not applied, per the task)

- `us.ak.statute.code`: anchor with `\b` and require a digit-first section after bare `AS` (e.g. `\bAS\s+§?\s*\d`).
- `us.al.statute.code`, `us.ar.statute.code`, `us.az.statute.code`, `us.co.statute.code`, `us.ct.statute.code`, `us.id.statute.code`, `us.in.statute.code`, `us.ks.statute.code`, `us.ms.statute.code`, `us.ne.statute.code`, `us.tn.statute.code`, `us.ut.statute.code`, `us.va.statute.code`, `us.wy.statute.code`, `us.state.statute.generic`: accept U+2013 and U+2012 inside section numbers.
- `us.fed.statute.usc`: accept en dash inside sections (`§ 300gg–92`) and en-dash ranges (`§§ 1331–34`); stop a trailing footnote digit after `.` from joining the section (`§ 1331.1`).
- `us.fed.federal_register`, `us.fed.session_law.statutes_at_large`, `us.short.case_at`, `us.short.supra`: accept en-dash page ranges and comma pin lists (`879–880`, `, 50, 65, 68`).
- `us.short.case_at`: include the preceding short case name (`Bruen, `) in the span (34/36 sampled lack it).
- `us.case.us_reports`, `us.case.federal_reporter`, `us.case.regional`: let case-name lookback start after `quoting`/`citing`/`cert. denied sub nom.` inside parentheticals, and tolerate `Commc 'ns`-style PDF spaces.
- `us.case.california`: span California-style `Name (Year) 32 Cal.4th 820, 825` from the name.
- `us.case.westlaw`: extend through `, at *N` and the court/date parenthetical.
- `us.short.id`: accept `at 604a–605a`, `at ¶ 20`, `at p. 85`, `at 214 n.7` and second pins.
- `us.fed.constitution`: accept the SCOTUS form `U. S. Const., Art. II, § 2, cl. 2` and `amend II` without a period.
- `us.secondary.law_review`: either span author/title/pin/year or document that the span is the volume–journal–page core.
- `us.fed.uspto.ptab_exhibit`, `us.record.ecf`: include the pin (`, 12:2–9`, ` at 1, 3`) and `Dkt. 219-1`.
- `us.short.supra`: exclude the signal `See` from the span, as the other rules do.
- `us.fed.rules.supreme_court`: do not match when a state abbreviation precedes (`Ill. S. Ct. R.`).
- `us.oh.statute.code`: cover `R.C. 2921.31(A)`, accept `§§`, and require a digit-first section (today `Ohio Rev. Code Ann. §§ 2907.31` yields section `Ann`).
- `us.il.statute.code`: cover `735 ILCS 5/13-116`.
- `us.tx.statute.code`: accept the small-caps/uppercase form `TEX. CIV. PRAC. & REM. CODE § 51.016`.
- `us.de.statute.code`: accept `8 Del. C. § 168` (no `tit.`).
- `us.fed.uspto.ptab_proceeding`: accept `IPR202500717` (hyphen lost in the PDF) and add a `Paper N` record companion (17 misses in one order).
- `us.record.appendix`: cover Delaware `A8 ¶¶ 12, 17` and `Compl. ¶ 6` / `SAC ¶ 51` record forms.
- `us.docket.number`: cover `Civil Action No. 25-cv-2200 (RDM)`, `USDC No. 2:22-CV-3015`, `No. 149, 2026` and Federal Circuit `2024-1094`.
- New rules needed: Ohio `2025-Ohio-2425`, Illinois `2022 IL 127258` / `2025 IL App (1st) 241354`, `Ohio St.3d`, `Ill. 2d`, `Crim.R. 3(A)`, `Tex. R. App. P.`.
- `us.case.us_reports`, `us.docket.number`, `us.fed.uspto.ptab_proceeding`: suppress page furniture (`Cite as:` heads, repeated captions, `Case: … Page:` headers) at the document layer, not in the rules.

## Limits

- **One AI labeler, no adjudication.** Labels are the agent's judgment. Close calls are documented in
  each label's `note`: running heads counted as true, internal `See supra, at 505` counted as a supra
  citation, and statute `(West 2024)` parentheticals not required for an exact span.
- **Sample sizes.** Most rules have n = 10 labeled. A rule with 10/10 true has a Wilson 95% lower
  bound of 0.72, so "100%" here means no false positive was seen in a small sample. It does not mean
  precision is perfect. Recall rests on 9 opinions (524 citations), one of which (Ohio) dominates the
  misses.
- **Corpus bias.** The corpus is recent (2025–2026), mostly published opinions, extracted from PDFs.
  No trial-court orders beyond 6 district opinions, no briefs, no TTAB, no markdown input. The
  linking checks (CITE001–CITE006) were not exercised, because the input is plain text.
- **Clean prose.** 19th-century fiction plus Darwin. It contains few `§` signs and little all-caps
  text, so it under-tests rules that misfire on headings and legal-looking prose.
- Nothing here was measured with `--input md`, `-layout` extraction, or HTML-native opinions
  (except the 2 N.Y. opinions).

## Reproduce

The helper scripts are not in the repo (see the top of this report). The steps:

1. **Fetch the opinions.**
   - CourtListener: query `https://www.courtlistener.com/api/rest/v4/search/?type=o&court=<id>&filed_after=<date>&order_by=dateFiled+desc&stat_Published=on` (anonymous; limits are 5/min and 50/hour). Download `https://storage.courtlistener.com/<local_path>` and run `pdftotext -enc UTF-8`. For the N.Y. Court of Appeals, which has only HTML, strip the tags and unescape entities.
   - govinfo: list the granules of each USCOURTS package with `api.govinfo.gov/packages/<pkg>/granules` (any api.data.gov key works, e.g. `DEMO_KEY`). Fetch `www.govinfo.gov/content/pkg/<pkg>/pdf/<granule>.pdf`.
   - PTAB: download the PDFs from the uspto.gov URLs in the manifest.
2. **Fetch the prose.** Download `https://www.gutenberg.org/cache/epub/<n>/pg<n>.txt` and keep only the text between the `*** START` and `*** END` markers.
3. **Check the corpus.** Every `text_sha256` and `words` value must match `corpus/manifest.json`.
4. **Run the tool.** `cargo build --release -p cite-detect`, then run `cite-detect --format jsonl --input text --fail-on never FILE` on each text. Record the `citation` lines with 160 bytes of context before and 100 after.
5. **Draw the sample.** Group the records by `rule_id`. Take every record when a rule has 10 or fewer, otherwise draw `random.Random(20261022).sample(xs, max(10, ceil(0.08 * len(xs))))`, iterating over the rules in sorted order. The resulting `sid` order matches `labeled_sample` in the JSON.
6. **Labels and recall.** All labels are in `labeled_sample` in the JSON (`label`, `span`, `note` per `sid`). The recall counts per opinion and per category are under `recall.docs`.

Compare the sha256 values in `corpus/manifest.json` before comparing numbers. CourtListener and
govinfo may re-extract or replace documents.
