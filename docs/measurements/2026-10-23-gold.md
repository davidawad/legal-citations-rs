## Method

- **Gold.** Each document was read in full and every citation labeled with its byte span,
kind, jurisdiction, normalized form and a form label (`corpus/gold/<doc>.jsonl`; the
conventions are in `corpus/gold/README.md`). Borderline references are marked `optional`:
they are not counted when missed, and a detection on one is neither a true nor a false positive.
- **Matching.** Each detection is assigned to the gold citation it overlaps most. A gold
citation is detected when a detection is assigned to it (recall). A detection is a true
positive when assigned to a counted citation, a false positive when it overlaps none
(precision). The span is exact when a detection's `span` equals the gold span byte for
byte; otherwise it is truncated, overextended, shifted or split. Catch-all (`unrecognized`)
hits are not detections here; they are reported only against misses.
- **Kind agreement.** For each detected citation, whether the best-overlapping detection has
the gold kind.

## Reproduce

```sh
cargo run --release -p cite-eval -- fetch   # rebuilds corpus/cache/gold, checks every sha256
cargo run --release -p cite-eval -- --date YYYY-MM-DD --revision REV
cargo run --release -p cite-eval -- --gate  # thresholds in corpus/gold/gate.json
```
